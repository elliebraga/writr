# writr • Editor de Livros, Capítulos e Personagens

Plataforma completa de escrita e gestão de obras com suporte a:
- Editor Tiptap em tela cheia com formatação e métricas de palavras
- Gestão condicional de capítulos e exportação customizável em PDF/DOCX
- Gestão de elenco e fichas de personagens com visual minimalista (Linear)
- Sincronização automática com Supabase e backup no localStorage
